# Particle form

BBS supports a subset of the Bedrock particle format.

## Editors

* In-mod particle editor
* External: [Snowstorm](https://snowstorm.app/)

## Timeline / film features

* `paused` track: control emission state
* `texture` track: animated texture changes
* **MoLang**: `variable.emitter_user_1` through `_6` for math-driven effects from the timeline
